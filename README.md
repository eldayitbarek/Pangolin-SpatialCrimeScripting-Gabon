# Pangolin-SpatialCrimeScripting-Gabon
The code of the methodology used to analyze pangolin wildlife trafficking in Gabon is organized according to the objectives. The data was obtained through participatory mapping of experts and community members in December 2025 and April 2026. The objectives are:-
1. Compare and contrast expert vs. community member’s spatio-temporal knowledge about three crime script stages of pangolin poaching in an under-researched geography at a national level;
2. Explore differences in spatial trajectories between three crime script stages; and
3. Explore spatial predictors of three crime script stages of pangolin poaching derived from both expert and community members’ spatial knowledge.
Objective 1 and Objective 3 are executed in R code while Objective 2 in python. Since github doesn't natively render R code chunk's outputs, a pdf is uploaded for Objective 1 and 3.
